# Visual Studio Code — AI Landing Page Clone

A responsive front-end recreation of the redesigned Visual Studio Code landing page, highlighting its multi-agent AI development workflow, modern dark UI, and product preview panels.

---

## Features

- **Navigation Bar**: Official Visual Studio Code branding, dropdown menu items (Features, Docs, Release Notes, etc.), search, and actions.
- **Hero Section**: 
  - Dynamic binary backdrop accent.
  - Centered typography and version highlight pill.
  - Windows download primary button with alternative platform access (Web, Insiders).
- **AI Editor Workspace Mockup**:
  - macOS-style window shell with traffic light controls.
  - Three-column layout featuring the code editor (`MailList.tsx`), AI agent refactoring panel, and active sessions tracker.
- **Responsive Design**: Adapts smoothly to desktop, tablet, and mobile screen sizes.

---

## Tech Stack

- **HTML5**: Semantic document layout
- **CSS3**: Flexbox, CSS Grid, custom scrollbars, and modern dark-mode color tokens
- **JavaScript**: (Optional) Dynamic canvas binary animation
